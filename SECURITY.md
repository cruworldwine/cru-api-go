# Security policy

## Reporting a vulnerability

Please report a vulnerability in this SDK privately, through GitHub's private vulnerability
reporting: open the repository's **Security** tab and choose **Report a vulnerability**, or go
straight to
[github.com/cruworldwine/cru-api-go/security/advisories/new](https://github.com/cruworldwine/cru-api-go/security/advisories/new).

**Never report a vulnerability in a public issue, pull request or discussion.** Do not include
real credentials, tokens or customer data in a report; describe them instead.

Tell us what the problem is, the versions it affects, and how to reproduce it. We will
acknowledge the report, keep you informed while we investigate, and credit you in the advisory
if you wish.

A vulnerability in the Cru Trading API itself, rather than in this SDK, can be reported the same
way; we will pass it on.

## Supported versions

Security fixes are made in the latest minor version only, released as a new patch version.

| Version | Supported |
|---|---|
| Latest minor (0.1.x) | Yes |
| Older | No |

Upgrade to the latest version to receive fixes.
